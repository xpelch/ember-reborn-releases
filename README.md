# Ember Reborn — releases

Ce dépôt contient **uniquement les installateurs Windows** d'Ember Reborn, un moteur de jeu natif non officiel. Le code source n'est pas publié ici.
This repository contains **only the Windows installers** for Ember Reborn, an unofficial native game engine. The source code is not published here.

**Téléchargement / Download:** voir l'onglet [Releases](../../releases) / see the [Releases](../../releases) tab.

## Ce que l'installateur contient / What the installer contains

- Le moteur et le lanceur, écrits par nous. / The engine and launcher, written by us.
- **Aucune ROM, aucun graphisme, son, musique, texte ni autre contenu de jeu.** / **No ROM, graphics, sound, music, text or other game content.**

Au premier lancement, le lanceur te demande ta propre copie du jeu original, obtenue légalement à partir d'une cartouche que tu possèdes. Tout le contenu de jeu est lu depuis ce fichier, sur ta machine, et n'est jamais redistribué.
On first launch, the launcher asks for your own copy of the original game, legally dumped from a cartridge you own. All game content is read from that file, on your machine, and is never redistributed.

## Avertissement Windows / Windows warning

L'installateur n'est pas signé numériquement. Windows Defender ou ton navigateur peuvent l'avertir comme « inconnu » ou le détecter à tort (`!ml`, détection heuristique). Vérifie l'empreinte SHA-256 publiée avec chaque release.
The installer is not code-signed. Windows Defender or your browser may warn about it or flag it by mistake (`!ml`, heuristic detection). Check the SHA-256 published with each release.
